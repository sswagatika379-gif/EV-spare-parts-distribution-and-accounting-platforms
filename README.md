# # EV Spare Parts Distribution and
# Accounting Management System

## About the Project
A desktop-based application developed to manage
EV spare parts distribution and accounting operations.

## Technologies Used
- Core Java
- MVC Architecture
- AWT
- Swing
- MySQL

## Features
- Spare Parts Management
- Inventory Management
- Customer Management
- Distribution Management
- Accounting Management

## Architecture
Model-View-Controller (MVC)

## How to Run
1. Clone the repository.
2. Open the project in your Java IDE.
3. Configure the database connection.
4. Import the SQL database.
5. Run the main class.EV-spare-parts-distribution-and-accounting-platforms
